# design-anti-cliche

**Diretrizes para design de UI moderno sem cara de IA.**  
Use ao criar interfaces, front-end ou sugerir estilos, garantindo que não tenham emojis, clichês ou ícones genéricos.

---

## Instructions
**Design de Interface Anti-Clichê**

### Resumo
Esta skill aplica regras estritas de design para garantir que aplicações tenham uma aparência moderna, premium e autêntica, evitando completamente o visual estereotipado de "aplicação feita por IA".

### Quando Usar
*   Sempre que criar código front-end (React, HTML/CSS, C#, etc.) ou estruturar UIs.
*   Ao sugerir estilos, layouts, paletas de cores ou tipografia.
*   Ao analisar ou revisar o design de uma aplicação fornecida pelo usuário.

### Regras Absolutas
*   **PROIBIDO USAR EMOJIS:** Não utilize emojis em textos de interface, placeholders, menus ou botões.
*   **Sem clichês de IA:** Evite ícones de "brilho" (sparkles), varinhas mágicas, gradientes neon (roxo/ciano) padronizados e sombras exageradas. A aplicação deve parecer um produto real de software moderno.

### Passo a Passo
1.  **Pergunte a Paleta de Cores:** Sempre pergunte ao usuário qual é a paleta de cores do projeto logo no início. Se ele não tiver, sugira algumas paletas sóbrias e modernas para aprovação.
2.  **Bibliotecas de Ícones:** Fuja do óbvio. Sugira e utilize bibliotecas de ícones modernas e com design diferenciado, como:
    *   Lucide Icons
    *   Phosphor Icons
    *   Tabler Icons
    *   Radix Icons
3.  **Estilo Premium:** Utilize tipografia contemporânea (Geist, Inter, Plus Jakarta Sans), foque em excelente uso de espaço em branco (*whitespace*) e bordas sutis, em vez de depender de componentes pesados.

### Gotchas
*   Caso o usuário mostre uma imagem de referência, aponte construtivamente os clichês antes de sugerir as melhorias baseadas nas regras acima.
*   Mantenha a regra de não usar emojis estrita para o design gerado, independente do contexto.
